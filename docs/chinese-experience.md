# 中文与跨境账户体验

此版本为中国用户改进了默认设置、账户机构选择和界面。

## 开始使用

- 新安装默认使用人民币（CNY）。已保存的币种不会被覆盖；完成过旧版引导、但没有保存本位币的安装会保留原来的 INR。
- 应用跟随系统语言。也可在「设置 → 语言」选择「简体中文」。
- 首次引导、添加账户和编辑账户时，可以点击「选择银行或券商」，按中文、英文或简称搜索，也可以按中国大陆、中国香港、新加坡、美国筛选。
- 选择机构会填入名称和图标。账户币种仍由你决定，请按实际账户选择 CNY、HKD、USD、SGD 等；同一券商的多个币种账户可用不同的账户名称区分。
- 自定义账户名称和图标仍可使用。人民币、港币、美元、新加坡元、新台币、澳门元均可离线选择。

## 机构范围

包括中国银行、建设银行、招商银行、工商银行、农业银行、交通银行、邮储银行、中信银行、浦发银行、兴业银行、民生银行、光大银行、平安银行、华夏银行、广发银行；汇丰香港、中银香港、恒生银行、富途证券；OCBC、DBS、UOB 新加坡；以及 IBKR、Chase、BofA、SoFi、Schwab、Capital One、AMEX US、Citi US、Wells Fargo、Fidelity、Vanguard、Robinhood。

中国银行与中银香港使用独立条目。机构图标随应用打包，显示时无需联网。图标来源见 [institution-assets.md](institution-assets.md)。

这里新增的是账户名称、图标和搜索预设。它们不代表新增了银行登录、账户同步、证券持仓或对应机构的短信解析能力；短信识别仍取决于现有解析器。

## 界面改进

设置页采用清晰分组和随主题变化的图标底色；常用操作扩大点击区域；余额和说明文字提高可读性。中文界面减少不自然的字间距，日期范围使用「9月1日」形式，跨年范围显示年份。

设计参考和实现说明见 [design.md](design.md)。现有 Material 3 架构与浅色、深色、动态主题设置继续使用。

## IBKR 持仓

首页新增「投资持仓」入口，可以使用自己的 IBKR Flex Token 和 Query ID 读取持仓报表。
这与机构名称/图标预设分开；仅选择 IBKR 图标不会启用连接。配置与限制见 [券商连接说明](brokerage-connections.md)。
